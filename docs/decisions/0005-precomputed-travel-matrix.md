# ADR-0005: 劇場間移動時間を事前計算行列で持つ
- Status: Accepted
- Date: 2026-07-07

## Context
経路検索 API は要素（origin×destination）課金で、`/plan` 実行のたびに呼ぶとコストが読めずレイテンシも悪化する。一方で劇場は有限個。

## Decision
対象劇場すべての組の移動時間を週次バッチで事前計算し KV に保持する。`/plan` 実行時の外部経路検索は、ユーザー指定の origin/destination の解決に限る（最大2回、24hキャッシュ）。

## Consequences
- ルート算出時の外部 API 呼出がほぼゼロになり、レイテンシ（N-01）とコスト（N-04）を両立。
- 劇場数増加時は行列の差分更新で対応。深夜・終電やリアルタイム遅延は考慮しない（MVP 割り切り、UI で注意喚起）。

## Alternatives considered
- リクエスト毎に経路検索: コスト・レイテンシとも不成立。
- 直線距離推定のみ: 実装は最軽量だが精度が低い。行列欠損時のフォールバックとしてのみ採用。
