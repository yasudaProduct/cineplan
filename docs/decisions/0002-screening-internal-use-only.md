# ADR-0002: 上映スケジュールは内部利用限定とする
- Status: Accepted
- Date: 2026-07-07

## Context
映画館の上映スケジュールには鉄道の GTFS/ODPT に相当する公式オープンデータや無料 API が存在せず、公式サイトからの取得に依存せざるを得ない。取得データを一覧表示・再配信するモデルは著作権・利用規約の両面でリスクが高い。

## Decision
取得した上映スケジュールは、ルート算出ロジックの入力としてのみ使用する。劇場×日付の上映一覧を表示・提供する機能は恒久的に作らない。予約は公式へ誘導する。

## Consequences
- 著作権法30条の4（享受目的でない利用）に沿った立て付けとなり、事実データの解析利用としてリスクを大きく下げられる。
- サービスの UI・API・要件すべてがこの制約に従う（一覧エンドポイントを持たない等）。機能の自由度は下がるが、持続可能性を優先。
- この原則を崩す変更はサービスの法的前提を変える重大事項。

## Alternatives considered
- スケジュール一覧サービス化: 既存大手（映画.com 等）と競合し、かつ規約・著作権リスクが直撃するため不採用。
- データ提供元へのライセンス交渉: スモールスタート方針（企業問い合わせ回避）と反するため現段階では見送り。将来拡大時に再検討。
