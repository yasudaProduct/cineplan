# ADR-0006: ルート算出をビットマスク DP で解く
- Status: Accepted
- Date: 2026-07-07

## Context
はしね鑑賞は「移動時間付きの区間スケジューリング」。マスト作品（最大3）を必ず含める制約があり、複数案の提示も必要。Workers の CPU 時間に上限がある。

## Decision
上映を開始時刻順に並べ、マスト達成状況を 3bit マスクで状態に持つ DP（dp[i][mask]）で解く。目的関数はタイブレークまで辞書式に固定し決定性を担保する。複数案は k-best（ビーム）化で得る。

## Consequences
- 計算量 O(N²×8)。実効 N を wish フィルタ・移動圏プルーニングで抑え、p95 1秒以内を狙う。
- マスト上限3は状態数（2³=8）を抑えるための意図的な制約（要件 F-03 と連動）。
- 同一作品の重複禁止を状態で厳密管理すると状態爆発（2^N）するため、k-best 列挙後に棄却する妥協を採用（05 §3 注記）。棄却で案数が不足する稀ケースは次善解で補う。

## Alternatives considered
- MIP / 外部ソルバ: 上映時刻が離散固定なので過剰。Workers で動かせない。
- 貪欲法: 高速だが最適性・複数案の質を保証できない。
