# ADR-0003: 上映抽出を LLM ベース（構造非依存）で行う
- Status: Accepted
- Date: 2026-07-07

## Context
劇場ごとに HTML 構造が異なり、CSS セレクタ狙い撃ちのスクレイパーはサイト改修のたびに壊れ、手作業メンテが破綻する。メンテナンスコストの最小化が要件。

## Decision
HTML をテキスト化し、JSON スキーマを与えて LLM に意味ベースで抽出させる。CSS セレクタに依存しない。

## Consequences
- サイトのマイナー構造変更で壊れにくく、保守工数を大幅削減。
- コストは LLM トークンに転嫁される（監視・最適化が必要 → 06 §8）。
- 抽出の誤り（欠損の創作的補完等）が新たなリスクになるため、妥当性検証（V1〜V6）とレビューキューで担保する。

## Alternatives considered
- CSS セレクタ方式: 高速・低コストだが保守破綻。不採用。
- セルフヒーリング（DOM 変更時に LLM がセレクタ修正）: 有用だが、抽出自体を LLM 化すればセレクタ自体が不要。将来の大改修時のフォールバックとしてのみ位置付け。
