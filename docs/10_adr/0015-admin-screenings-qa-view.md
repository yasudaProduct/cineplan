# ADR-0015: 管理サイトに抽出検証用の上映データ表示を追加（0002 のスコープ明確化）
- Status: Accepted
- Date: 2026-07-20

## Context
ADR-0002 / docs/08 §0・§1 は「劇場×日付の上映一覧を返す API・画面」を禁止してきた。趣旨は、取得データを利用者に閲覧・再配信させる利用（享受目的利用）になると著作権法30条の4 の立て付けが崩れるため、これを防ぐこと。一方、運用では取込済み screenings の内容確認（抽出品質の検証・公式サイトとの目視突合・障害調査）のたびに D1 を直接クエリする必要があり、管理サイトに確認手段が欠けていた。管理サイトには既にレビュー詳細の抽出結果テーブル（07 §2.5）・R2 スナップショット閲覧（08 §4 の内部利用）という同種の内部表示が存在する。オーナーが 2026-07-20 に本画面の追加を判断した（個人運用・admin はオーナーのみ閲覧可能）。

## Decision
管理サイト（Cloudflare Access + adminGuard 配下）に、劇場・日付を指定して取込済み screenings を閲覧する検証用画面 `/admin/screenings` を追加する。ADR-0002 の禁止は「利用者向け機能・公開エンドポイント」を対象とすることを明確化し、本画面は 08 §4 の R2 スナップショットと同じ内部利用（検証・デバッグ目的）として許容する。条件:

- 管理サイト配下のみ。利用者向け web・公開 API には恒久的に出さない（ADR-0002 の本体は不変）。
- SSR 画面のみ。JSON 等の機械可読な一覧エンドポイントとして提供しない。
- エクスポート・共有・再配信機能を付けない。
- 画面に抽出検証目的である旨を明記する。

## Consequences
- 先方サイトへのアクセスは一切発生しない（D1 の読取のみ）。アクセス態様（08 §1 原則3）は不変。劇場側の robots.txt・利用規約との関係も変化しない。
- 30条の4 の立て付けは「利用者に享受させない」ことに依存しており、運営者本人の検証目的の閲覧はこれを崩さない。ただし本画面を日常のスケジュール閲覧用途（今日何を観るかを選ぶ等の享受目的）に常用しない。その用途が必要になったら本 ADR を見直し、専門家確認を経る。
- docs/08 §0・§1 と CLAUDE.md ハードルール1 に「利用者向け・公開面が対象」のスコープ注記を追記した（08 §6 の手続に基づく変更記録が本 ADR）。

## Alternatives considered
- **D1 直接クエリ（wrangler d1 execute）での確認継続**: 可能だが JST 変換・作品名 join を毎回手書きすることになり、公式サイトとの突合という運用実態に耐えない。
- **利用者向け web への一覧公開**: ADR-0002 の禁止そのもの。検討対象外。
